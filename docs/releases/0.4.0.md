onmywave.fm 0.4.0 refines the library layout, search, and keyboard navigation.

- Browse your library in an inset panel that ends above the floating player, with a consistent gap at wide and narrow window sizes.
- Song rows have even spacing and square edges. Keyboard focus stays visible around songs, sidebar navigation, filters, and queue controls.
- Clear library searches with one click. Typing waits briefly before searching, and results keep the same width as the scrollbar appears or disappears.
- Table headers extend through the scrollbar area and stay aligned while scrolling.
- Includes security patches for Electron and build dependencies.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.4.0-arm64.dmg`, open it, and drag onmywave.fm into Applications. Existing updater-enabled installations can update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for downloads and updater files. UI verification used the actual renderer with a synthetic library at desktop and narrow window sizes. Live Jellyfin streaming, VoiceOver, and an update between installed releases were not exercised for this release.
