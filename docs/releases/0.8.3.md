# onmywave.fm 0.8.3

- Open large artist, album, and playlist track lists faster. Selection, playback, and playlist reordering still work across the full list.
- Search artists as you type. Song and album searches start sooner, and pressing Enter runs them immediately. Previous results stay visible while the new results load.
- News Bucket and DJ schedule updates appear as preparation progresses. Playback settings are ready to edit again as soon as a save is confirmed.
- The DJ break notice shows when the break will play.
