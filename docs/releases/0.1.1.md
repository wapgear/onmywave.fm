onmywave.fm 0.1.1 makes the DJ controls smaller and easier to scan.

- Expand Current DJ to change the selected news profile. The selector stays hidden until you need it.
- Open the info button for scheduling help and automatic news preparation details.
- Expand upcoming or previously heard news to read the recording and its sources.
- Keep keyboard focus when expanding or collapsing DJ controls.

This release also includes the song-details shortcut from the player cover, fixes for lyric clicks and unavailable seeking, and playback and library performance improvements merged since 0.1.0.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.1.1-arm64.dmg`, open it, and drag onmywave.fm into Applications. Existing updater-enabled installations can update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for downloads and updater files. Optional news preparation can incur provider charges. DJ interface checks used local fixtures without provider requests. Live Jellyfin streaming, VoiceOver, and an update between installed releases were not exercised for this release.
