# onmywave.fm 0.8.2

- Choose a dynamic or static accent and backdrop gradient independently of the color theme. Dynamic colors follow the Now Playing artwork.
- Save named custom accents and gradients, switch to them instantly, and double-click a saved tile to rename it.
- App notices keep the selected backdrop visible. Update progress sits alongside the message and action, and notices keep a consistent height as actions appear or disappear.

Signed and notarized for Apple silicon Macs running macOS 13 or later. Install from the DMG or update from within the app.
