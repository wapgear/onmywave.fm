onmywave.fm 0.3.2 fixes song-list playback and selection, and preserves your latest listening position when quitting.

- Click a song-list cover, title, or row to play it. Click the bottom-left player cover to open the current song’s info.
- Hold Command to select songs. Selected rows use a background highlight, with no checkboxes. Keyboard navigation moves focus without selecting songs.
- Quit and reopen to continue with the saved queue, current song, playback position, and edited shuffle order. The session opens paused, ready for Play.
- Normal quit waits for the final playback save. Restarting to install an update requests a save before invoking the updater. Periodic checkpoints remain available after an unexpected exit.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.3.2-arm64.dmg`, open it, and drag onmywave.fm into Applications. Existing updater-enabled installations can update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for downloads and updater files. Verification covered song-list playback, Command selection, and native quit/relaunch through production main, preload, renderer, and storage with isolated synthetic data. Live Jellyfin streaming, real audio decoding, VoiceOver, and an update between installed releases were not exercised for this release.
