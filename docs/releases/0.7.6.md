# onmywave.fm 0.7.6

- Add Remove song with confirmation, durable local hiding, and retryable server synchronization. The optional server companion records requests with a seven-day grace period; automatic file cleanup requires a separate worker.
- Expand Song details from the listening sidebar, with responsive artwork and metadata, smoother resizing, and consistent spacing with Lyrics.
- Select song rows with a click and play them with a double-click. Keep the artwork play button and keyboard playback available, and fit row numbers to larger libraries.
- Use Electron's asynchronous protected-storage APIs while preserving existing saved credentials.

Signed and notarized for Apple silicon Macs running macOS 13 or later. The DMG supports manual installation; existing installations receive this version through the in-app updater.
