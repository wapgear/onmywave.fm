First release of onmywave.fm, a macOS music player for your Jellyfin library.

- Browse and search songs and albums, and create and edit playlists.
- Keep a listening queue with shuffle, repeat, and session restoration.
- Add optional spoken news between songs using your own sources and provider keys.
- Audition bundled DJ voices without provider keys.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.0.1-arm64.dmg`, open it, and drag onmywave.fm into Applications. A ZIP is also available. Automatic updates are not included in this release.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains download checksums. Optional news and generated voice features can incur provider charges. This is an early release; real-server playback and playlist behavior have not been verified as part of packaging.
