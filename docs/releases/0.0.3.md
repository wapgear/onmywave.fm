onmywave.fm 0.0.3 fixes the play icon alignment in the player button.

The play triangle is now optically centered. The pause icon, button dimensions, and keyboard controls are unchanged.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.0.3-arm64.dmg`, open it, and drag onmywave.fm into Applications, replacing the previous version. Version 0.0.2 users can also update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for the downloads and updater files. Optional news and generated voice features can incur provider charges. Real-server playback and an upgrade between two installed updater-enabled releases have not been verified as part of packaging.
