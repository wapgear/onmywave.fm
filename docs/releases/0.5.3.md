onmywave.fm 0.5.3 brings a new news editorial workspace and keeps playback running when you close the window.

- Review stories and saved recordings in one News bucket workspace, with editable source, selection, and writing settings and a full-height story inspector.
- News preparation saves its collection, selected story and reason, written script, and audio publication progress. Explicit Resume can continue from a valid saved checkpoint instead of repeating completed work.
- Selection and writing use separate policies. Saved selection reasons and source coverage are visible, and review exclusions follow the editorial configuration while heard stories remain excluded across rooms.
- Closing the window keeps the app and playback running in the background. Use the macOS menu bar icon to reopen the window or explicitly quit. The same lifecycle is implemented and checked for Windows source builds.
- A second launch reopens the existing app, protecting the local preparation index from competing writers.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The macOS app is Developer ID signed and notarized by Apple.

Download `onmywave-0.5.3-arm64.dmg`, open it, and drag onmywave.fm into Applications. Existing updater-enabled installations can update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for downloads and updater files.
