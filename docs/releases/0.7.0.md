onmywave.fm 0.7.0 refines News Bucket and gives the music library more room.

- Browse Upcoming, Check news, Past news, Favorites and Settings from a compact category row. Narrow windows use a category selector.
- Read prepared stories in a quieter editorial layout, with headline-first lists, a larger story heading and a round Listen control. Existing favorites, listening history and news preparation settings keep their behavior.
- Resize or collapse the main navigation sidebar, with saved widths, keyboard controls and tooltips for compact navigation.
- Local macOS packages now include the updater configuration needed to discover and download releases.

Requires an Apple silicon Mac running macOS 13 or later, plus your own Jellyfin server. Optional news preparation uses your configured providers and can incur charges.

The macOS downloads are Developer ID signed and notarized by Apple. Download `onmywave-0.7.0-arm64.dmg`, open it, and drag onmywave.fm into Applications. Updater-enabled installations can update from Settings → General → About and updates.

The corresponding source archive, updater metadata, blockmaps and `SHA256SUMS.txt` are included. Verification uses the real renderer with synthetic stories and simulated audio, desktop and narrow layouts, all three themes, keyboard and focus checks, news preview and Settings flows, reduced motion and quality/security checks. No live model or speech requests were made. Native VoiceOver, physical audio devices and an update between installed release versions were not exercised.
