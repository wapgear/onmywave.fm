onmywave.fm 0.7.1 improves the macOS window header.

- Center the traffic lights in a taller header so they stay clear of the main panel when navigation is collapsed.
- Keep the library, listening drawer and sidebar spacing aligned with the window controls.
- Retain the existing 64px minimum sidebar width.

Requires an Apple silicon Mac running macOS 13 or later, plus your own Jellyfin server. Optional news preparation uses your configured providers and can incur charges.

Download `onmywave-0.7.1-arm64.dmg`, open it, and drag onmywave.fm into Applications. Updater-enabled installations can update from Settings → General → About and updates.

The macOS downloads are Developer ID signed and notarized by Apple. The corresponding source archive, updater metadata, blockmaps and `SHA256SUMS.txt` are included.

The header was verified in a native Electron window at 960×700 with collapsed and expanded navigation and synthetic library content. Native VoiceOver, fullscreen transitions and an update between installed release versions were not exercised.
