onmywave.fm 0.3.0 adds Light, Coffee and Dark themes and refines controls throughout the desktop app.

- Choose a theme in Settings → General → Appearance. Your choice is remembered between launches.
- Search and filter fields share consistent sizing and focus rings. Volume handles, selected states and text have clearer contrast across all three themes.
- Settings, DJ editing and news setup use shorter labels and compact help icons. Required setup, provider costs, limits and live status remain visible.
- Clicking song artwork in the library, albums, playlists or player opens song details without changing playback. Keyboard activation and focus return work too.
- Playback error actions have consistent spacing, and skipping the last failed track clears the stale error.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.3.0-arm64.dmg`, open it, and drag onmywave.fm into Applications. Existing updater-enabled installations can update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for downloads and updater files. Optional news preparation can incur provider charges. UI checks used isolated Electron fixtures across all three themes. Live Jellyfin streaming, provider-generated audio, VoiceOver and an update between installed releases were not exercised for this release.
