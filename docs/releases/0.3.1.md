onmywave.fm 0.3.1 makes catalog searches and large queues more responsive and adds control over what plays next.

- Choose Play next or Add to end from song menus, selected songs, albums and playlists. Multi-song additions keep their source order and duplicate entries.
- Reorder upcoming songs with the visible six-dot drag handle. Move buttons and keyboard Up, Down, Home and End controls are available too. Queue edits preserve the current song, playback position and play/pause state.
- Manual shuffle order is reflected in actual playback and saved between launches. Restored sessions remain paused.
- Large queues render only the visible rows. Catalog searches use bounded parallel requests and cancel searches that are no longer needed.
- DJ setup shows preparation status, saved recordings and playback readiness, with a direct next action. Saved recordings remain available without provider keys.
- A page rendering failure offers recovery while keeping the player and navigation available.
- Critical catalog, storage, news-delivery and playback behavior now runs in CI. Electron is updated to 43.7.6.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.3.1-arm64.dmg`, open it, and drag onmywave.fm into Applications. Existing updater-enabled installations can update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for downloads and updater files. Optional news preparation can incur provider charges. Verification covered queue edits, duplicate entries, shuffle/repeat, paused restore, DJ delivery and page recovery with isolated fixtures, including 10,000-entry queues. Live Jellyfin streaming, provider-generated audio, VoiceOver and an update between installed releases were not exercised for this release.
