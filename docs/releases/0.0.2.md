onmywave.fm 0.0.2 adds automatic updates for future releases.

- Check for updates at startup, every six hours, or manually in Settings → General → About and updates.
- Choose when to download, follow download progress, and restart when you are ready to install.
- Open song actions from a row's context menu.
- Update build dependencies and resolve dependency security alerts.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

If you use 0.0.1, install this version manually once. Download `onmywave-0.0.2-arm64.dmg`, open it, and drag onmywave.fm into Applications, replacing the previous version. A ZIP is also available. Version 0.0.2 includes the updater for subsequent releases.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for the downloads and updater files. Optional news and generated voice features can incur provider charges. Real-server playback and an upgrade between two installed updater-enabled releases have not been verified as part of packaging.
