onmywave.fm 0.2.0 improves application updates and whole-library playback.

- Update prompts have clearer spacing, separated actions, and room above player messages. Deferred updates collapse into a compact pill.
- Download progress and update-state changes animate smoothly and respect reduced motion. Keyboard focus stays with the update controls when you defer or reopen them.
- Repeat all now continues through your whole library. Shuffle discovers more songs as the queue advances, and library-loading errors offer a retry without interrupting current audio.
- The repeat button cycles through off, all, and one, with matching icons and accessible labels.

Requires an Apple silicon Mac running macOS 12 or later and your own Jellyfin server. The app is Developer ID signed and notarized by Apple.

Download `onmywave-0.2.0-arm64.dmg`, open it, and drag onmywave.fm into Applications. Existing updater-enabled installations can update from Settings → General → About and updates.

The source archive contains the corresponding build inputs and license notices. `SHA256SUMS.txt` contains checksums for downloads and updater files. Optional news preparation can incur provider charges. UI and playback checks used isolated Electron fixtures. Live Jellyfin streaming, VoiceOver, and an update between installed releases were not exercised for this release.
